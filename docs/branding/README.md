# LikenessForge visual identity

![LikenessForge logo](logo.svg)

By [Kieran Simkin](https://kieransimkin.co.uk/), part of [DanceFlow](https://kieransimkin.co.uk/danceflow/). Original vector artwork, 15 October 2026, under the repository MIT licence.

The split face contour and repair brackets distinguish LikenessForge from the other tools. Shared family grammar: 128-unit square, rounded 30-unit frame, 5.5-unit round strokes, plum `#171124`, mint `#bff7df` and gold `#f5ce85`. `logo.svg` is the dark badge; `logo-monochrome.svg` is a transparent dark symbol for light surfaces; `logo.png` is the 256px companion. The same SVG is packaged for the desktop window icon. These marks contain no portrait, external font, script or provider logo.

Preserve square proportions, allow at least 8/128 width clear space and label tiny icons with the tool name. Use the monochrome version on a contrasting light surface. The symbol denotes the repair workflow; it does not certify identity, likeness accuracy or model-provider endorsement.
